- 단일 HTML 파일, Gist 연동, GitHub Pages 배포

## AI정보통합 (이 시스템)

- 폰 수집앱 → GitHub Private → git pull → OneDrive 수집됨\ → 정리 → 대시보드 push
- 보안\ 폴더 파일은 대시보드에 절대 업로드하지 않음
- 정리 작업 시 `_정리및갱신규칙.md` 반드시 읽고 진행
