# Claude 활용 가이드

> Claude Code에서만 쓸 수 있는 플러그인 · 스킬.
> 도구 종류가 아니라 **"무엇을 하려는가(목적)"** 기준으로 묶었다.
> (출처: 유튜브 '메이커 에반' 채널, 400시간 실무 검증)

---

## ① 기획 · 방향 잡기 — 코드 짜기 전

성급하게 코딩을 시작하기 전에 방향을 잡아 헛코드를 방지한다.

- **brainstorming** (Superpowers 플러그인)
  기능 구현 전 타겟 유저·성공 기준·제약 사항을 역질문해 기획의 구멍을 찾는다.

- **office** (G-Stack 플러그인)
  "정말 돈을 내고 쓸 수요가 있는가", "가장 좁은 진입점은 어디인가" 등 YC 파트너 수준의 날카로운 사업 질문 6가지로 아이디어를 다듬는다.

- **맥퍼커(McPocker) 방식**
  `grill-me` 등을 활용해 도메인 파일(`context.md`)을 만들고 용어 사전·위키를 구축한다. 도메인 맵핑과 DDD 아키텍처링 담당.

---

## ② 코드 품질 · 검토 — 짠 코드를 더 좋게

성급하게 짜여 엣지 케이스에서 터지는 버그를 사전에 차단한다.

- **grill-me** (Matt Pocock's Skills)
  작성한 코드·설계안에 "이 상태 값을 왜 여기 뒀느냐"며 동료 개발자처럼 압박 질문을 던져 실수를 찾아낸다. PR 올리기 전 '깐깐한 사수' 역할.

- **improvement-architecture** (Matt Pocock's Skills)
  기존 코드 구조를 통째로 분석해 재사용성을 높이고 테스트를 쉽게 만드는 리팩토링 로드맵을 제안한다.

- **sub-agent-driven-development** (Superpowers 플러그인)
  크고 복잡한 작업을 서브 에이전트들에게 분산해 메인 세션의 컨텍스트 오염을 막고, 2단계 검증(기획 준수 + 코드 품질)을 수행한다.

- **Codex Review** (플러그인)
  Claude가 작성한 코드를 OpenAI 모델 시각으로 한 번 더 검토한다. 동일 모델이 놓치는 세부 버그를 잡는다. 워크플로우 마무리 단계에서 활용.

- **React Best Practices** (Vercel 스킬)
  최신 React·Next.js 모범 사례를 주입. 구식 패턴·useEffect 남용·서버/클라이언트 컴포넌트 경계 모호성을 자동 교정한다.

---

## ③ 컨텍스트 관리 — 긴 작업에서 Claude 안 망가지게

- **browse** (G-Stack 플러그인)
  백그라운드에 크롬 세션을 상시 유지해 일반 AI 서핑보다 20배 빠른 속도(100~200ms)로 로그인·폼 채우기·스크린샷·콘솔 에러 잡기 등 QA를 수행한다. 보통 30분이면 무너지는 컨텍스트를 2시간 이상 지속시킨다.

- **플러그인 점진적 설치**
  도구를 한 번에 다 설치하면 컨텍스트가 무거워져 답변 성능이 떨어진다. 가장 필요한 것부터 하나씩 설치해 익숙해진 뒤 확장한다.

## ④ 산출물 자동화

- **PPTX & PDF** (보너스 스킬)
  구현된 소스 코드·요약 데이터를 기반으로 폰트·크기·색상이 정돈된 슬라이드(PPTX)·보고서(PDF)를 자동 추출한다. 개발자가 취약한 문서화·발표 자료 제작을 자동화.
