# Claude 활용 가이드

> Claude Code에서만 쓸 수 있는 플러그인 · 스킬.
> 도구 종류가 아니라 **"무엇을 하려는가(목적)"** 기준으로 묶었다.
> (출처: 유튜브 '메이커 에반' 채널, 400시간 실무 검증)

---

## ① 기획 · 방향 잡기 — 코드 짜기 전

성급하게 코딩을 시작하기 전에 방향을 잡아 헛코드를 방지한다.

- **brainstorming** (Superpowers 플러그인)
  기능 구현 전 타겟 유저·성공 기준·제약 사항을 역질문해 기획의 구멍을 찾는다.

- **office** (G-Stack 플러그인)
  "정말 돈을 내고 쓸 수요가 있는가", "가장 좁은 진입점은 어디인가" 등 YC 파트너 수준의 날카로운 사업 질문 6가지로 아이디어를 다듬는다.

- **맥퍼커(McPocker) 방식**
  `grill-me` 등을 활용해 도메인 파일(`context.md`)을 만들고 용어 사전·위키를 구축한다. 도메인 맵핑과 DDD 아키텍처링 담당.

---

## ② 코드 품질 · 검토 — 짠 코드를 더 좋게

성급하게 짜여 엣지 케이스에서 터지는 버그를 사전에 차단한다.

- **grill-me** (Matt Pocock's Skills)
  작성한 코드·설계안에 "이 상태 값을 왜 여기 뒀느냐"며 동료 개발자처럼 압박 질문을 던져 실수를 찾아낸다. PR 올리기 전 '깐깐한 사수' 역할.

- **improvement-architecture** (Matt Pocock's Skills)
  기존 코드 구조를 통째로 분석해 재사용성을 높이고 테스트를 쉽게 만드는 리팩토링 로드맵을 제안한다.

- **sub-agent-driven-development** (Superpowers 플러그인)
  크고 복잡한 작업을 서브 에이전트들에게 분산해 메인 세션의 컨텍스트 오염을 막고, 2단계 검증(기획 준수 + 코드 품질)을 수행한다.

- **Codex Review** (플러그인)
  Claude가 작성한 코드를 OpenAI 모델 시각으로 한 번 더 검토한다. 동일 모델이 놓치는 세부 버그를 잡는다. 워크플로우 마무리 단계에서 활용.

- **React Best Practices** (Vercel 스킬)
  최신 React·Next.js 모범 사례를 주입. 구식 패턴·useEffect 남용·서버/클라이언트 컴포넌트 경계 모호성을 자동 교정한다.

---

## ③ 컨텍스트 관리 — 긴 작업에서 Claude 안 망가지게

- **browse** (G-Stack 플러그인)
  백그라운드에 크롬 세션을 상시 유지해 일반 AI 서핑보다 20배 빠른 속도(100~200ms)로 로그인·폼 채우기·스크린샷·콘솔 에러 잡기 등 QA를 수행한다. 보통 30분이면 무너지는 컨텍스트를 2시간 이상 지속시킨다.

- **플러그인 점진적 설치**
  도구를 한 번에 다 설치하면 컨텍스트가 무거워져 답변 성능이 떨어진다. 가장 필요한 것부터 하나씩 설치해 익숙해진 뒤 확장한다.

## ④ 산출물 자동화

- **PPTX & PDF** (보너스 스킬)
  구현된 소스 코드·요약 데이터를 기반으로 폰트·크기·색상이 정돈된 슬라이드(PPTX)·보고서(PDF)를 자동 추출한다. 개발자가 취약한 문서화·발표 자료 제작을 자동화.

## ⑤ Claude Co-work — 협업형 자동화 작업 공간

채팅형 인터페이스를 넘어 사용자가 정의한 목표를 AI가 독립적으로 수행하는 에이전틱 워크스페이스.

### Claude Code vs Co-work 비교

| 구분 | Co-work | Code |
|---|---|---|
| 형태 | 데스크톱 앱 (시각적 워크스페이스) | 터미널 기반 CLI |
| 주 목적 | 사무 업무·데이터 수집·비즈니스 자동화 | 소프트웨어 개발·테스트·디버깅 |
| 핵심 산출물 | xlsx·pptx·docx 등 문서 파일 | 소스 코드·Git Commit |
| 주요 특징 | 크롬 브라우저 조작·원격 제어·영구 메모리 | 로컬 쉘 명령 실행·코드 전체 분석 |

### 4대 핵심 기능

1. **로컬 파일 직접 관리** — 폴더 단위 권한 제어. 민감 작업 시 승인 요청.
2. **크롬 브라우저 연동** — 웹 클릭·데이터 수집·QA 자동화.
3. **병렬 작업** — 복잡한 업무를 하위 태스크로 분할해 동시 처리.
4. **전문 산출물 생성** — 실제 함수·차트가 포함된 엑셀·PPT 파일을 로컬에 생성.

### 고급 기능

- **디스패치** — 모바일 앱으로 집 PC의 Claude에 원격 작업 지시.
- **영구 메모리** — 세션 종료 후에도 유지되는 프로젝트별 메모리.
- **커넥터(MCP)** — Notion·Slack·GitHub 등 외부 협업 툴 연동.

### 주의점

- **토큰 비용 폭탄 리스크**: 반복 클릭·대규모 파일 탐색 시 비용 급증 가능.
- **10분 룰**: 민감 작업 알림 후 10분 무응답 시 자동 취소.
- **CAPTCHA 한계**: 대형 플랫폼 크롤링은 Python 스크립트로 대체하는 것이 효율적.

## ⑥ 서브에이전트 — 병렬 분산 실행

메인 세션이 **오케스트레이터(팀장)** 역할을 하고, 독립 작업들을 **서브에이전트(팀원)** 로 분기시켜 병렬 실행하는 구조.

```
Claude Code 메인 세션 (오케스트레이터)
├─ 서브에이전트 A → 작업 A
├─ 서브에이전트 B → 작업 B
└─ 서브에이전트 C → 작업 C
        ↓ 완료 후 메인에 최종 요약만 반환 → 메인 컨텍스트 경량 유지
```

- 각 서브에이전트는 **별도의 깨끗한 컨텍스트 윈도우**를 가짐
- **병렬 실행 = 토큰 절약 아님** (에이전트별 독립 소비), 속도 향상이 목적

### 병렬 실행 가능 조건 (3가지 모두 충족해야)

| 조건 | 설명 |
|---|---|
| 의존성 없음 | A 결과가 B에 필요 없음 |
| 공유 파일 없음 | 같은 파일 동시 수정 X |
| 독립 완결 가능 | 각 작업이 단독으로 완료 가능 |

### 사용법

**① 직접 지시 (명시적 병렬 실행)**
```
아래 작업들을 병렬 서브에이전트로 동시에 실행해줘:
- 에이전트1: [작업 A]
- 에이전트2: [작업 B]
```

**② 판단 위임 (추천)**
```
아래 개발 목록에서 병렬로 처리 가능한 것들을 서브에이전트로 동시에 작업해줘:
1. ...
2. ...
```
→ Claude Code가 의존성 분석 후 병렬/순차를 직접 판단

**③ 서브에이전트 명시 요청**
```
서브에이전트를 띄워서 이 작업 결과를 스펙 파일 기준으로 검증해줘
서브에이전트가 저 코드베이스를 읽고 auth 흐름을 요약해줘
```

**④ 백그라운드 확인 명령어**
```
/tasks    ← 실행 중인 에이전트 목록 및 진행 상황 확인
/compact  ← 컨텍스트 크기 줄이기
/clear    ← 세션 컨텍스트 초기화
```

### CLAUDE.md 라우팅 규칙 (자동 판단 세팅)

```markdown
## Sub-Agent Routing Rules

병렬 실행 (아래 조건 모두 충족 시):
- 독립 기능, 파일 분리, 의존성 없음
- 3개 이상의 무관한 작업

순차 실행 (하나라도 해당 시):
- 선행 결과 필요 (B가 A 결과 필요)
- 공유 파일/상태 있음
- 범위 불명확

백그라운드:
- 리서치/분석 작업
- 결과가 즉시 필요 없음
```

### 토큰·세션 주의사항

- 서브에이전트는 **5시간 롤링 윈도우 한도 우회 불가** — 채팅창을 새로 열어도 같은 계정의 동일 5시간 버킷 소비
- 웹·데스크톱 앱·Claude Code 터미널 **모두 동일한 풀 공유**
- 병렬 실행 시 토큰 소비가 빨라지므로 **남발 주의**

### 언제 쓰나

| 상황 | 적합 여부 |
|---|---|
| 독립적인 기능 3개 이상 동시 개발 | ✅ 적합 |
| 대형 코드베이스 탐색 (영역별 분리) | ✅ 적합 |
| 리서치·분석 후 메인 작업 | ✅ 적합 |
| 의존성 있는 순차 작업 | ❌ 부적합 |
| 세션 한도 절약 목적 | ❌ 효과 없음 |

## ⑦ CLAUDE.md 완전 가이드 — AI에게 브레이크와 성공 기준 주기

*출처: 유튜브 '미드나잇 로그 Midnight Log' — 카파시 Vibe Coding 노하우 정리*

> "AI는 코드를 못 짜는 게 아니다. 너무 잘 짜고, 너무 빠르고, 너무 자신 있게 짜는 게 문제다."  
> 명령보다 **제약 사항**과 **성공 기준**을 제공하는 시스템 프롬프트가 필수다. 이 파일이 CLAUDE.md다.

### 파일 배치 방법

| 적용 범위 | 경로 | 설명 |
|---|---|---|
| **로컬 프로젝트** | 프로젝트 루트에 `CLAUDE.md` | 해당 폴더 내 AI 툴 실행 시 자동 흡수 |
| **글로벌 전체 (추천)** | `~/.claude/CLAUDE.md` | 어느 디렉토리에서나 항상 적용 |

### 한국어 환경 커스텀 규칙 (CLAUDE.md 포함 권장)

1. **문장 끝 콜론(:) 사용 금지** — AI는 영어식 습관으로 한국어 출력 시 콜론을 자주 씀. 자연스러운 마침표(.)로 강제
2. **새 파일 생성 시 한국어 헤더 주석 필수** — 맨 윗줄에 해당 파일의 역할을 한 줄 주석으로 기재
   - 예: `# 사용자 인증 상태를 관리하는 컨텍스트 프로바이더`
   - 효과: AI가 파일 전체를 다 읽지 않아도 필요한 파일을 정확히 골라 작업 가능
3. **큰 작업 시 [계획서 → 체크리스트 → 컨텍스트 노트] 프로세스 강제** — AI가 코드 짜기 전 문서를 먼저 쓰게 해 다음 날도 맥락 유지
4. **작업 마무리 전 테스트 실행 자동화** — "끝났습니다" 전에 테스트 명령 실행 + 결과 보고 의무화
5. **의미 단위 커밋 (Atomic Commits)** — "이 커밋 메시지를 한 문장으로 설명 가능한가?" 기준으로 분리. 수십 개 파일을 하나의 커밋으로 뭉뚱그리지 않게

## ⑧ 웹사이트 제작 워크플로우 — Claude Code 5단계

*출처: 유튜브 영상 정리 (Claude Code Auto Mode 기반)*

> 핵심 철학: **"구조는 인간이 가이드하고, 감각적인 디테일은 AI의 해석력에 맡긴다."**

### 1단계: 레퍼런스 & 에셋 준비 (Preparation)

- **비주얼 타겟팅**: Dribbble · Pinterest에서 원하는 무드의 사이트 스크린샷 3~5개 확보
- **미디어 에셋 생성**: Claude에게 이미지 생성 프롬프트를 먼저 짜달라고 한 뒤, AI 이미지/비디오 생성기(Midjourney, Luma 등)에 넣어 소스 미리 확보

### 2단계: 환경 설정 & 스킬 주입 (Setup)

- Claude Code를 **Auto Mode**로 실행 (프로젝트 전용 빈 폴더)
- 디자인 가이드라인이나 UI 라이브러리(21st.dev 등) 지침 플러그인을 Claude에게 학습
- 프롬프트 예시:
  ```
  첨부한 프론트엔드 디자인 스킬 파일을 읽고, 앞으로 이 프로젝트의 모든 코딩은 이 가이드를 엄격히 준수해.
  ```

### 3단계: 역질문을 통한 뼈대 구축 (Build)

- 첫 요구사항을 던질 때 반드시 Claude가 **먼저 생각하게** 유도
- 프롬프트 예시:
  ```
  [주제] 웹사이트를 만들 거야. 완벽한 결과물을 위해 필요한 정보가 있다면 7가지 이내로 질문해줘.
  ```
- Claude의 역질문(기술 스택·섹션 구성·컬러 등)에 답하면 깔끔한 HTML 뼈대 한 번에 생성

### 4단계: 의도 중심 폴리싱 (Refinement)

- **인텐트(Intent) 기반 수정**: "심심하다", "비싸 보이게" 등 시각적 감각으로 지시
- 프롬프트 예시:
  ```
  전체적인 톤은 좋은데 하단 섹션이 좀 심심해. 마우스 커서 움직임에 부드럽게 반응하는 마이크로 인터랙션을 넣어서 훨씬 비싸 보이게 다듬어줘.
  ```
- **모바일 전용 패스**: 단순 화면 축소 말고 모바일 사용자 전용 레이아웃 최적화 요청

### 5단계: 프로덕션 배포 (Deployment)

- **내부 파일 압축**: 프로젝트 폴더 자체가 아니라 폴더 내부 파일(index.html, images/ 등)을 선택해 압축
- **호스팅 업로드**: 정적 호스팅(Hostinger 등)에 업로드 후 커스텀 도메인 연결
