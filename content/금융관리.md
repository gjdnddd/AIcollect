# 금융관리 가이드

> 가계부 분석·소비 관리·자산 운용에 관한 방법론.

---

## 소비 분석 워크플로우 (NotebookLM + Gemini)

AI를 활용한 2단계 소비 분석 방법.

### 1단계: NotebookLM에서 팩트 추출

1. 카드사·가계부 앱(토스, 뱅크샐러드 등)에서 **최근 3~6개월치 소비 내역을 xlsx/CSV로 다운로드**
2. NotebookLM 새 노트북에 업로드

**[프롬프트 A] — 카테고리 분류 + 미분류 역질문**

```
업로드한 지출 내역을 분석할 때 다음 기준을 참고해서 카테고리를 유추하고 분류해 줘:
1. '네이버파이낸셜'/'네이버페이': 1~2만 원대 → 배달/식비, 3만 원 이상 → 쇼핑(생필품)
2. '우아한형제들' → 배달의민족(식비), '쿠팡이츠' → 식비, '쿠팡' → 쇼핑(생필품)
3. '신세계아이앤씨' → 식비/생필품 (이마트 장보기)
4. 'KG이니시스'/'토스페이먼츠' 중 정액·매달 반복 → 구독 서비스(고정비)
분류 어려운 내역은 날짜/금액/가맹점명을 표로 정리해서 역질문해 줘.
```

3. 미분류 내역 답변 후 팩트 리포트 요청

**[프롬프트 B] — 최종 팩트 리포트**

```
정리된 데이터로 아래 3가지를 리포트로 작성해 줘:
1. 고정 지출·구독 서비스 항목 리스트와 월 총합 (누수 의심 항목 포함)
2. 카테고리별 지출 총액·비율(%), 지출 집중 취약 요일·시간대 패턴
3. 누적 지출·결제 횟수 상위 5개 결제처, 외식비·변동 교통비 각각 합산
```

---

### 2단계: Gemini Gems에서 피드백 받기

1. Gemini → Gems → 새 Gem 생성
2. Gem 이름: `스토아 철학 자산관리 비서`

**[프롬프트 C] — Gem 설정 지침**

```
정체성: 소비 데이터를 냉철하게 분석하고 구조조정 방안을 제시하는 뼈 때리는 전문 자산관리사이자 스토아 철학 기반 절약 멘토.

지침:
1. 칭찬보다 고쳐야 할 문제점을 날카롭고 직설적으로 지적.
2. 특정 시간대(밤 배달), 플랫폼 과몰입(쿠팡 잦은 결제), 불필요한 고정비 누수 집중 파헤치기.
3. 충동구매 패턴에 스토아 철학적 관점 곁들여 조언.
4. 다음 달 소비 20% 절감을 위한 행동 수칙 3가지를 액션 플랜으로 제시.
말투: 차갑고 냉정하되, 자산 성장을 진심으로 바라는 멘토 톤. 제공된 데이터에만 기반.
```

3. Gem 채팅창에 NotebookLM 팩트 리포트 텍스트 붙여넣기 → 피드백 수령
