# Gemini 활용 가이드

> 출처: 유튜브 "제미나이는 이제 이렇게 사용하세요." (구글 AI 생태계 활용 브랜드 런칭 사례)

---

## 구글 AI 생태계 브랜드 런칭 워크플로우

1인이 하루 만에 브랜드 기획 → 제품 사진 → 웹페이지 → SNS 콘텐츠 → 홍보 영상까지 완성하는 파이프라인.

---

## 1단계 — 브랜드 두뇌 구축 (NotebookLM + Gemini Jems)

AI가 일관된 브랜드 아이덴티티를 유지하며 작업하도록 기준점 세팅.

- **NotebookLM**: 구글 Docs에 브랜드 가이드라인 작성 → 구글 드라이브 연동으로 소스 추가. 드라이브 문서 수정 시 실시간 동기화 가능 (파일 업로드 방식보다 유지보수 편리)
- **Gemini Jems**: 맞춤형 챗봇 생성 + NotebookLM 노트를 지식 베이스로 지정 → 매번 브랜드 배경 설명 없이 맞춤 결과물 즉시 출력

---

## 2단계 — 제품 사진 생성 (Gemini 이미지 생성)

스마트폰으로 찍은 원본 사진 한 장으로 마케팅용 이미지 제작.

- 제미나이 채팅창에 사진 업로드 → '이미지 만들기' 선택
- **광고용 제품 컷**: 깔끔한 배경·부드러운 조명·고화질로 자동 변환
- **무드 컷**: 라벨에 브랜드명 추가, 배경·분위기 프롬프트로 자유롭게 변경

---

## 3단계 — 웹페이지 제작 (Google Stitch)

- 원하는 디자인 컨셉·색상·구성을 텍스트로 입력 → 웹페이지 자동 생성
- 생성된 텍스트는 더블클릭으로 직접 수정, AI 제작 이미지 업로드로 교체 가능
- 넷리파이(Netlify) 배포 옵션으로 즉시 실제 웹사이트로 빌드

---

## 4단계 — SNS 마케팅 자동화 (Formelly)

- 브랜드 가이드 문서 업로드 → 로고·컬러·톤앤매너 원클릭 주입
- 제품 이미지 + 설명 등록
- 신제품 런칭 캠페인 기획 요청 → SNS 채널 최적화 비주얼 콘텐츠 자동 생성

---

## 5단계 — 홍보 영상 제작 (Gemini Video + Google Vids)

- **Gemini 동영상 만들기**: 무드 컷 이미지 첨부 + 프롬프트 → 숏폼 세로형 영상 제작. 카메라 무빙 방향은 대화로 수정 가능
- **Google Vids**: 생성된 영상에 AI BGM(분위기 텍스트 입력 → 자동 생성) + AI 목소리 내레이션 삽입 → 완성도 높은 홍보 영상

---

## 활용 포인트

| 도구 | 역할 |
|------|------|
| NotebookLM | 브랜드 지식 베이스 구축 + 실시간 동기화 |
| Gemini Jems | 브랜드 전용 맞춤 챗봇 |
| Gemini 이미지 | 제품 사진 고급화 |
| Google Stitch | 랜딩 페이지 즉시 제작 |
| Formelly | SNS 콘텐츠 자동 생성 |
| Google Vids | 숏폼 영상 + BGM + 내레이션 |
