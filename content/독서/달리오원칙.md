## 1장. 삶의 기본 원칙

### 1.1 꿈 + 현실 + 결단력
- 원하는 것(꿈) + 현실이 어떻게 작동하는지(현실) + 결단력 = 성공 공식
- 대부분 실패 이유: 현실을 회피하거나 결단력이 없어서
- **삶의 원칙이란**: 목표→현실→결단의 반복 사이클을 최적화하는 도구

### 1.2 진실을 추구하라
- 좋은 결과의 유일한 길: 현실을 있는 그대로 보는 것
- 인간의 본성이 진실을 회피하도록 설계돼 있음 → 의식적 노력 필요
- 불편한 현실을 직면하는 것이 장기적으로 훨씬 낫다

### 1.3 극도의 개방성(Radical Open-Mindedness)
- 내가 틀릴 수 있다는 것을 항상 전제
- 반박을 공격으로 받아들이지 말고 더 나은 정보로 받아들이기
- 가장 영리한 사람이 아니라 가장 개방적인 사람이 이긴다

### 1.4 자연을 관찰하라
- 자연은 진화와 적자생존으로 작동하는 최고의 설계자
- 삶도 같은 원리: 실패 → 적응 → 성장
- 고통·실패를 피하려 하지 말고 성장의 신호로 받아들여라

### 1.5 진화하라
- 인간의 최고 목적 = 진화와 성장
- "진화하지 않으면 죽는다" — 자연의 법칙이 삶에도 적용
- 안주는 쇠퇴의 시작

### 1.6 고통 + 성찰 = 성장
- 고통 없이 성장 없음. 불편함은 성장의 신호
- 고통을 무시하거나 피하면 같은 실수 반복
- 프로세스: 고통 인식 → 원인 성찰 → 행동 변화

### 1.7 2차 결과와 3차 결과를 보라
- 1차 결과(눈앞): 대부분 좋아 보임 (쉬운 길, 즉각적 보상)
- 2차·3차 결과: 장기적 영향 — 진짜 중요한 것
- 예: 운동(1차 고통) → 건강(2차 이득) / 솔직한 피드백(1차 불편) → 성장(2차 이득)

### 1.8 책임을 져라
- 자신의 결과에 100% 책임지기 (외부 탓 금지)
- 피해자 마인드셋 = 성장 차단
- "내가 어떻게 했더라면 달랐을까?"가 성장의 질문

### 1.9 기계처럼 자신을 바라보라
- 자신을 기계(시스템)로 보기 — 감정적 거리 유지
- 나쁜 결과 = 내가 나쁜 게 아니라 **시스템 오작동** → 수정하면 됨
- 자기 자신을 객관적으로 분석하는 능력이 최고의 능력

## 2장. 5단계 프로세스

목표 달성을 위한 반복 사이클 — 어디서 막혔는지 진단해야 한다.

### 2.1 목표를 설정하라
- 원하는 것을 명확히 정의. 모호한 목표 = 모호한 결과
- "진정으로 원하는 것 vs 원한다고 착각하는 것" 구분하기
- 목표는 구체적이고 측정 가능해야 함

### 2.2 문제를 파악하라
- 목표 달성을 막는 장애물을 명확히 식별
- 불편한 진실을 회피하지 말 것 (1장 1.2 적용)
- 문제를 인정하는 것이 해결의 절반

### 2.3 근본 원인을 진단하라
- 증상이 아닌 원인 치료
- "왜?"를 최소 3번 반복해 진짜 원인 발굴
- 표면 문제에 집중하면 같은 문제 반복됨

### 2.4 계획을 설계하라
- 진단이 완료된 후에야 설계
- 구체적인 행동 계획: 누가, 무엇을, 언제
- 여러 시나리오 고려

### 2.5 실행하라
- 계획이 아무리 완벽해도 실행 없으면 의미 없음
- 규율과 결단력으로 완수
- 실행 중 문제 발견 시 → 2.2로 돌아가 반복

## 3장. 극도의 개방성

### 3.1 두 가지 최대 장벽 인식
- **에고(Ego)**: 틀렸다는 걸 인정하기 싫은 본능 → 좋은 정보 차단
- **블라인드 스팟(Blind Spots)**: 내가 보지 못하는 영역 → 모른다는 것조차 모름
- 이 두 가지만 인식해도 이미 남들보다 앞서 있다

### 3.2 아이디어 실력주의 실천
- 직급·나이·경력이 아닌 아이디어의 질로 결정
- 이중 사고: 내 의견을 강하게 갖되, 더 나은 것이 있으면 기꺼이 바꾸기
- 목표는 이기는 것이 아니라 더 나은 답을 찾는 것

### 3.3 에고·블라인드 스팟 극복
- 에고는 없앨 수 없음 → 관리하는 것
- 방어 반응을 인식하는 순간 절반은 이긴 것
- 내 약한 영역에서 강한 사람의 의견을 적극적으로 구하기

### 3.4 신뢰도 가중 의사결정
- 모든 의견이 동등한 가치를 갖지 않음 → **신뢰도(Believability)** 도입
- 신뢰도 높은 사람 = 해당 분야 반복 성공 + 논리적 근거 + 실패에서 배운 사람
- 삼각측량: 신뢰도 높은 2~3명 의견 비교 → 일치하면 강한 확신, 불일치하면 더 파고들어야 할 신호

### 3.5 열린/닫힌 마음 신호
**닫힌 마음 신호:**
- 상대 말을 끊고 자기 말을 함
- "하지만", "그런데"로 바로 반박
- 질문보다 주장이 많음
- 틀렸을 때 인정 안 하거나 화제를 돌림

**열린 마음 신호:**
- 상대 말을 끝까지 듣고 질문함
- "내가 틀릴 수 있다"를 전제로 대화
- 다른 의견에 호기심을 느낌
- 틀렸을 때 오히려 배웠다고 생각

### 3.6 본성을 관리하는 시스템
- 인간은 본능적으로 닫혀 있도록 설계됨 → 없앨 수 없음
- **해법 1**: 고차원 자아 훈련 — 본능적 반응 인식 → 한 박자 멈춤 → 이성적 판단
- **해법 2**: 시스템과 도구 활용 — 본성을 이기게 해주는 구조를 만들어라
- "당신의 본성을 바꾸려 하지 마라. 본성을 관리하는 시스템을 만들어라"

## 4장. 사람들을 이해하라

### 4.1 위대한 사고 vs 평균적 사고
- 평균적 사고: 표면 정보를 그대로 받아들임
- 위대한 사고: 표면 아래 원리·패턴을 파고듦
- 차이는 지능이 아니라 **더 깊이 파고드는 습관**

### 4.2 의미 있는 일과 관계
- 달리오 수십 년 결론: 진정으로 가치 있는 것은 딱 두 가지
- **의미 있는 일**: 진심으로 몰입할 수 있는 일, 과정 자체에서 보람
- **의미 있는 관계**: 진실을 말해줄 수 있는 관계, 불편한 피드백도 주는 관계
- 돈·명예·권력은 이 두 가지를 대체할 수 없다

### 4.3 뇌는 도구다
- 고차원 뇌(논리·이성) vs 저차원 뇌(감정·본능) — 대부분 저차원 뇌가 이김
- "뇌가 당신을 통제하게 두지 마라. 당신이 뇌를 통제해야 한다"
- 나쁜 결정 = 내가 나쁜 게 아니라 도구 오작동 → 도구를 고치면 됨

### 4.4 의식적/무의식적 처리
- 대부분의 결정은 무의식에서 이미 내려진다. 의식은 사후 합리화
- 해법 1: 좋은 원칙을 반복해서 무의식에 심기
- 해법 2: 강한 직관이 올라올 때 왜 그런 느낌인지 파고들기

### 4.5 심리·유전적 차이
- 사람들은 태어날 때부터 다르게 배선(Wiring)됨
- 자신의 배선을 아는 것 = 자기 이해의 출발점
- 타인의 배선을 아는 것 = 관계의 출발점
- 약점을 바꾸려 하기보다 이해하고 시스템으로 보완

### 4.6 배선 파악과 기대 조정
- 사람에게 맞지 않는 역할을 주는 것은 배치의 실패
- 반복적으로 실망하는 관계는 기대 자체가 잘못됐을 가능성
- 사람을 바꾸려 에너지 쓰지 말고 → 맞는 역할을 찾거나 기대를 조정하라

## 5장. 효과적인 의사결정

### 5.1 모른다는 것을 아는 것
- 가장 똑똑한 사람은 자신이 모든 것을 알 수 없다는 것을 안다
- 함정 1 — 과잉확신 / 함정 2 — 분석 마비
- 불확실성을 인정하되 최선의 확률로 행동하라

### 5.2 종합(Synthesis)
- 좋은 의사결정의 핵심 = 정보를 의미 있는 그림으로 엮어내는 것
- 종합 3단계: ① 핵심·비핵심 구분 → ② 패턴 찾기 → ③ 단순화
- "한 문장으로 설명 못 하면 아직 제대로 이해하지 못한 것"

### 5.3 시간 흐름 속 종합
- 현재 스냅샷이 아니라 변화의 방향과 속도를 보기
- 과거→현재→미래를 연결하면 진짜 통찰이 나옴
- 단기 노이즈 vs 장기 트렌드 구분

### 5.4 층위 오르내리기
- **높은 층위 (큰 그림)**: 목표·원칙·방향 / "왜 이걸 하는가?"
- **낮은 층위 (디테일)**: 구체적 실행·숫자 / "어떻게 할 것인가?"
- 큰 그림만 보면 실행에서 무너지고, 디테일에만 빠지면 방향을 잃는다

### 5.5 논리 + 직관 + 신뢰도 높은 의견 조합
- 세 가지를 적절히 조합하는 것이 지혜
- 논리: 데이터와 사실 / 직관: 경험 축적 패턴 / 신뢰도 높은 의견: 전문가
- 세 가지 일치 → 강하게 행동 / 엇갈림 → 더 파고들어야 할 신호

### 5.6 기댓값 계산
- 기댓값 = 확률 × 결과의 크기
- 좋은 결정 기준 = 기댓값이 플러스인지 (결과가 아닌 결정의 질로 판단)
- 비대칭적 베팅 찾기: 잃을 것은 작고 얻을 것은 큰 기회

### 5.7 결정의 우선순위
- 삶의 결과 80%는 20%의 핵심 결정에서 나온다
- **고영향 결정**: 되돌리기 어렵고 방향을 바꾸는 결정 → 시간·에너지 집중
- **저영향 결정**: 되돌리기 쉬운 결정 → 빠르게 결정하고 넘어가기

### 5.8 실패→원칙화 + 결과 수용
- 실패 = 데이터 → "왜 실패했는가?" → 원칙으로 정리
- 할 수 있는 모든 것을 다 했다면, 그 다음은 결과를 받아들여라
- 전체를 관통하는 한 문장: "현실을 있는 그대로 보고, 최선을 다해 행동하고, 결과로부터 배워라. 그리고 반복하라"
