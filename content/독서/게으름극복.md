# 나태한 완벽주의자 — 게으름 극복

## 활용 방안
- 게으름 분석 페이지 — 생활 점검하고 싶을 때
- 루틴 만들 때 참고 페이지
- 분기·반기 점검 시 활용 페이지
  1. 추가를 통한 개선 + 제거를 통한 개선 — 효과 있는 것 추가, 효과 없는 요소 제거. 위임 가능한 것은 위임
  2. 중요한 일 먼저 하기
  3. 생체리듬 — 최고의 시간대 파악
- 바로 적용: 손전등 집중력 전략(산만함 알아차리고 돌아오기), 위임(집안일 도우미)

## 게으름의 유형 파악 — 업무가 하기 싫어질 때 왜 그런지 파악
- **혼란**: 무엇을 할지 모르는 상황 → 구체적 실행계획, 전문가 코칭
- **할 수 없다는 두려움**: 행동과 감정을 분리, 작은 행동으로 시작
- **실패의 두려움**: 실패는 더 나아지기 위해 반드시 거쳐야 하는 과정으로 받아들이기 — 실패를 배움으로, 도전을 기회로 재정의
- **피로**: 육체 피로는 휴식, 정신 피로는 생활패턴 변경. 하기 싫어서 피로하면 조금만 하되 꾸준히
- **무관심**: 반발심 내면 확인, 가치관 점검
- **자신에 대한 믿음 부족**: 그 순간의 실패가 나를 규정하지 않는다. 마음챙김이 도움
- **의욕상실**: 바꿀 수 없는 것을 받아들이는 평온함 + 바꿀 수 있는 것을 바꾸는 용기 + 둘을 분별하는 지혜
- **편안함 추구**: 진짜 게으름. 재밌는 것부터 하고 중요한 건 안 하는 상태 — 그냥 중요한 것을 할 수밖에 없다

## 게으름을 이기는 방법
1. 러키비키식 상황 받아들이기 — 실패는 배움의 과정
2. 작은 행동으로 시작하기 — 기분·컨디션과 무관하게 할 수 있을 정도로 작게
3. 마음챙김 명상 — 호흡, 오감 느끼기
4. 마음 다스리기
   - 마음상태 파악: 90초 법칙(감정 발생 시 90초 동안 화학작용, 이후는 내가 선택) / 몸의 반응 확인(피로·병으로 감정이 발생했을 수 있음)
   - 받아들이기: 감정 발생을 인식하고 받아들인다
   - 흘려보내기: 감정 페르소나 만들기(이름 짓기 → 트리거 찾기 → 트리거 없앨 방법 적기), 감정과 나를 동일시하지 않기, 명상으로 현재로
   - 행동하기: 해결책 찾기, 가치관과 일치하는 아주 작은 행동을 꾸준히
5. 감각적 욕망 이기기 — 식욕·성욕·수면욕 등, 굴복했을 때의 죄책감과 안 했을 때의 아쉬움을 글로 적어보기

## 손전등 집중력 전략
- 주의 산만해짐을 알아차리고 반복적으로 목표 대상으로 되돌리는 것
- 되돌아올 때: 시각화 연습(한 가지 물건에 집중), 방해 없는 환경 조성, 규칙적 운동, 마음챙김, 명상

## 불편함 연습
- 단식, 기다릴 때 아무것도 안 하기, 찬물 샤워, 단 것 안 먹기 등

## 생체리듬
- 가장 에너지가 높은 타이밍에 가장 중요한 일을 한다
- 가장 에너지가 높은 시점을 찾는다

## 루틴 만들기
1. 컨디션과 상관없이 실행할 수 있을 만큼 쉽게 만든다
2. 몸을 움직이는 루틴이어야 한다
3. 꾸준함을 유지한다
4. 기간을 정하고, 기간이 다하면 검토해서 수준을 올린다
5. 안 좋은 행동은 한 번에 끊는 것이 좋다
6. 기존 루틴에 끼워넣는 것이 매우 효과적이다

## 중요한 일 먼저 하기
1. 할 일 목록 만들기: 25가지 목표 → 최상위 5개 선정 → 나머지 20개는 절대 해서는 안 되는 목표로 분류 → 일정 기간 수행 후 반복
2. 마감·중요성(했을 때의 이득) 기준으로 우선순위 선별
3. 더 미루고 싶은 일을 우선순위로 선별

## 목표 수립
- SMART 목표: 구체적 / 측정가능 / 실현가능 / 가치관 일치성 / 마감 기간이 있을 것
- 목표의 상태 파악: 현재 목표가 장기·중기·단기 기준에서 어디에 위치하는지 본다
