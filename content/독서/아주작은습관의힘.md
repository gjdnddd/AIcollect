# 아주 작은 습관의 힘 (Atomic Habits, James Clear)

---

## 핵심 구조

**습관 루프**: 신호(Cue) → 열망(Craving) → 반응(Response) → 보상(Reward)

**행동 변화 4법칙**: 분명하게(신호) / 매력적으로(열망) / 쉽게(반응) / 만족스럽게(보상)
→ 나쁜 습관을 끊을 땐 4가지를 역으로 뒤집는다

**핵심 원칙**: 목표를 세우는 게 아니라 **시스템**을 만드는 것. 목표는 방향만 정하고, 결과는 시스템이 만든다.

---

## 챕터별 핵심

### Part 1. 아주 작은 습관이 만드는 극적인 변화

- 매일 1%씩 좋아지면 1년 후 약 37배 좋아진다
- 결과는 습관의 "지체된 측정값" → 변화가 눈에 안 보이는 낙담의 골짜기를 견뎌야 한다
- 가장 강력한 변화: 결과 변화 → 과정 변화 → **정체성 변화** 순
- "살 빼야지"가 아니라 "나는 건강한 사람이다"로 프레임 전환 → 모든 행동은 "내가 되고 싶은 사람"에 대한 투표 한 표

### Part 2. 분명해야 달라진다 (신호)

- **습관 점수표**: 평소 행동을 좋음/나쁨/중립으로 분류 → 무의식적 신호를 의식 위로
- **실행 의도**: "나는 [시간]에 [장소]에서 [행동]을 할 것이다"
- **습관 쌓기**: "[기존 습관]을 한 후, 나는 [새 습관]을 할 것이다"
- 의지력보다 **환경 디자인**이 강력 — 원하는 행동 신호는 눈에 보이게, 나쁜 습관 신호는 시야 밖으로

### Part 3. 매력적이어야 달라진다 (열망)

- **유혹 묶기**: 해야 하는 일 + 하고 싶은 일을 짝짓기
- 보상의 "기대"가 실제 보상보다 행동을 더 강하게 이끈다
- 원하는 행동이 당연한 규범인 **집단에 들어가는 것**이 가장 강력한 전략

### Part 4. 쉬워야 달라진다 (반응)

- 습관은 완벽함이 아니라 **반복 빈도**로 만들어진다
- 좋은 습관은 마찰을 줄이고, 나쁜 습관은 마찰을 늘린다
- **2분 룰**: 새 습관은 2분 이내로 줄여서 시작. 목표는 "일단 시작하는 습관" 마스터

### Part 5. 만족스러워야 달라진다 (보상)

- 즉시 보상받는 행동은 반복, 즉시 처벌받는 행동은 피하게 된다
- **습관 추적기**: 진전이 보인다는 즉각적 만족감 제공
- 핵심 규칙: **"두 번 연속 거르지 않기"**

### Part 6. 심화

- 유전자는 맞는 환경에선 강점 — 인기 습관보다 내게 맞는 습관 선택
- **골디락스 법칙**: 현재 능력의 경계선에 있는 과제에서 동기부여 최대화. 성공의 가장 큰 적은 실패가 아니라 **지루함**
- 마스터리 = 자동화된 습관 + 의도적 연습. 연례 리뷰로 주기적 재점검

## 적용 체크리스트

### 정체성·목표
- [ ] 새 목표 → "목표"가 아닌 "매일 반복할 시스템"으로 먼저 정의
- [ ] "OO을 해야 한다" 대신 "나는 OO한 사람이다"로 정체성 문장 만들기
- [ ] 변화가 안 느껴지는 구간 = 실패 신호가 아님. 누적 효과 믿고 지속

### 인식·기록
- [ ] 무의식적으로 하는 행동들을 좋음/나쁨/중립으로 분류해보기
- [ ] 중요한 습관 1~2개에 한해 추적기(체크표, 캘린더) 만들기

### 환경 설계
- [ ] 원하는 행동의 신호(도구, 책, 운동 매트)를 눈에 잘 보이는 곳에 배치
- [ ] 피하고 싶은 행동의 신호(스마트폰, 군것질)를 시야 밖으로
- [ ] 좋은 습관 도구·환경 → 전날 밤 미리 준비(프라이밍)
- [ ] 줄이고 싶은 행동에 일부러 단계 하나 더 추가(마찰 증가)

### 시작 장벽 낮추기
- [ ] 새 습관 → "[시간]에 [장소]에서 [행동]" 형식으로 구체적으로 한 줄 작성
- [ ] 확실한 기존 습관 뒤에 새 습관 하나 붙이기(습관 쌓기)
- [ ] 만들고 싶은 습관을 2분 이내로 시작할 수 있는 버전으로 축소

### 매력·동기
- [ ] 해야 하지만 미루는 일 + 하고 싶은 일 짝짓기: "[운동]을 한 후 [좋아하는 콘텐츠]를 본다"

### 사회적 장치
- [ ] 만들고 싶은 습관과 관련된 모임·커뮤니티에 들어갈 수 있는지 점검
- [ ] 끊고 싶은 습관 → 어길 시 공개적·고통스러운 대가가 따르는 계약서 작성

### 보상·만족감
- [ ] 습관 직후에 정체성과 충돌하지 않는 작은 보상 붙이기
- [ ] **"두 번 연속 거르지 않기"** — 하루 빠졌으면 다음 날은 꼭

### 정기 리뷰
- [ ] 연말/반기마다 "잘된 것 / 안된 것 / 배운 것" 3줄 리뷰 캘린더에 일정으로 박기
