## 🧠 사고방식

- 중요한 결정 전 "확신하는 것 / 불확실한 것"을 두 칸으로 나눠 적기 — [목표/동기] (실천·달리오)
- 결정을 실행 전 한 문장으로 요약해보기 (안 나오면 이해 부족 신호) — (실천·달리오)
- 층위 체크: ①큰 그림(목표·방향에 맞나) ②디테일(실행이 현실적인가) 둘 다 통과해야 실행 — (실천·달리오)
- 세 가지 도구 체크: 논리(데이터)+직관+신뢰도 높은 의견 → 일치하면 강하게, 엇갈리면 더 파고들기 — (실천·달리오)
- 기댓값 표 그리기: 성공/실패 확률 × 결과 크기로 계산 — (실천·달리오)
- 고영향/저영향으로 분류해 저영향은 5분 안에, 고영향은 시간을 충분히 투입 — (실천·달리오)
- 근본 원인을 찾을 때 "왜?"를 최소 3번 반복하기 — (달리오)
- 종합 3단계 적용: 핵심/비핵심 구분 → 패턴 찾기 → 단순화 — (달리오)
- 본능적 반응을 감지하면 한 박자 멈추고 이성적으로 판단하기 — [감정] (달리오)
- 강한 직관이 올라오면 "왜 이런 느낌인가?"를 일지에 기록 — [감정] (달리오·실천)
- 좋은 원칙을 반복해서 무의식에 심기 — [습관] (달리오)
- 5단계 프로세스로 막힌 지점 진단하기: 목표→문제→원인→계획→실행 — [목표/동기] (달리오)

- 삶을 개선하는 질문 자문: "나에게 특별한 점은 무엇일까?" — [정체성] (반복)
- 의지박약을 탓하기 전에 "목표 자체가 너무 컸던 건 아닌지" 점검하기 — [사고방식] (반복)
- 성공을 "내 최선을 다했는가?"로 재정의해 판단 기준 삼기 — [정체성] (실천·내면)

## 💓 감정 (상태 관리)

- 박스 호흡 4-4-4-4: 들숨 4초 → 참기 4초 → 날숨 4초 → 참기 4초 — (내면·실천)
- STOP 기법: Stop → Take a breath → Observe → Proceed (반응 전 멈춤) — [사고방식] (내면·실천)
- 앵커링: 최상의 상태 기억을 신체 신호(주먹·손가락)와 연결해두고 필요 시 재현 — (내면·실천)
- 만트라 하나 만들어두고 흔들릴 때 반복 ("지금 이것만", "여기 지금") — (내면·실천)
- 감각 초점화: 한 가지 감각에 완전히 집중해 잡생각 차단 — (내면)
- Float Up: 의식을 머리 위로 띄워 3인칭 관찰자 시점으로 감정 격리 — [사고방식] (내면)
- 부정적 자기 대화를 사실 기반 중립 언어로 바꿔 말하기 — [사고방식] (내면)
- 압박·위협을 도전·기회로 재구성(Reframing)하기 — [사고방식] (내면)
- 감사 연습: 저녁에 감사할 것 3가지 적기 — [습관] (내면·실천)
- 의도 설정: 아침에 "오늘 내가 원하는 상태는?" 정하기 — [목표/동기·습관] (내면·실천)
- 회복 루틴: 부정적 상태 후 개인별 초기화 시퀀스 실행 — [습관] (내면)
- 멘탈 블록 4단계: ①3인칭 관찰 ②작은 변화 포인트 찾기 ③긍정 감정 삽입 ④앵커링 고정 — [사고방식] (내면)
- 시각화: 역경에도 평정심을 유지하는 자신을 5가지 감각으로 생생히 그리기 — [사고방식] (내면·실천)
- 부담되는 일(발표·어려운 대화) 전 하루 30초씩 성공 장면을 오감으로 상상 — [습관] (반복)
- 감정이 올라온 직후 결정 금지, 하루~이틀 뒤 재검토 — [사고방식] (실천)
- 손실 후 서두름 제거(S-L-O-W), 바로 재진입 금지 — [습관] (실천)
- 위기에 압도되면 가장 작은 문제 하나부터 해결해 통제감 회복 — [습관] (반복)
- "끝나면 행복" 대신 "지금 감사할 게 뭐가 있나"로 질문 전환 — (반복)
- 하루 중 작은 디테일(환경·배려) 하나를 의식적으로 알아채기 — (반복)

## 🔄 피드백 (자기 점검 · 배움)

- 신뢰할 수 있는 2~3명에게 "내가 못 보고 있는 게 뭐냐" 직접 묻고 끝까지 듣기 — [사고방식·관계] (달리오·실천)
- 신뢰도 높은 2~3명의 의견을 삼각측량해 대조하기 — [사고방식] (달리오)
- 의견 충돌 시 "저 사람이 맞다면 나는 무엇을 놓쳤나?" 먼저 생각하기 — [사고방식] (실천)
- 반박이 불편하게 느껴지면 그 의견을 더 진지하게 듣기 — [사고방식] (실천)
- 나쁜 결과 후 "내가 어떻게 했더라면 달랐을까?" 자문하기 — [사고방식] (달리오)
- 실패를 "왜 실패했는가?"로 분석해 원칙으로 정리하기 — [사고방식] (달리오)
- 일일 3초 점검: 말을 끊었나 / 틀림을 인정했나 / 다른 의견에 호기심을 느꼈나 — [사고방식·관계] (실천)
- 분기 점검: 3개월 전 대비 변화 / 이대로면 3개월 후 / 지금 무엇을 바꿀까 — [목표/동기] (실천)
- 매주 한 번 "이번 주 저지른 작은 실수는?" 점검해 위기 전 균열 발견 — [습관] (습관·반복·실천)
- 반기/연말에 "잘된 것·안된 것·배운 것" 3줄 리뷰 일정을 캘린더에 박기 — [습관] (습관)

## ⚙️ 습관 (행동 설계)

- 2분 룰: 새 습관을 "절대 실패할 수 없다" 싶을 만큼 2분 이내로 작게 시작 — (습관·반복·실천)
- 작은 질문 자문: "지금 당장 할 수 있는 가장 작은 행동은?" — [목표/동기] (반복·실천)
- 실행 의도: "[시간]에 [장소]에서 [행동]을 한다"를 한 줄로 작성 — (습관)
- 습관 쌓기: "[기존 확실한 습관]을 한 후 [새 습관]을 한다"로 연결 — (습관·실천)
- 신호 배치: 좋은 행동 신호(운동화·책)는 눈에 보이게, 나쁜 신호는 시야 밖으로 — (습관·실천)
- 마찰 조절: 좋은 습관은 마찰을 줄이고, 나쁜 습관은 단계를 하나 더 추가 — (습관·실천)
- 유혹 묶기: 해야 하는 일 + 하고 싶은 일 짝짓기 — (습관)
- 습관 점수표: 평소 행동을 좋음/나쁨/중립으로 분류하기 — [사고방식] (습관)
- 중요한 습관 1~2개에 한해 추적기(체크표·캘린더) 만들기 — (습관)
- "두 번 연속 거르지 않기" — 하루 빠졌으면 다음 날은 꼭 — (습관·실천)
- 습관 직후 정체성과 충돌하지 않는 작은 보상 붙이기 — (습관·반복)
- 좋은 습관 도구·환경을 전날 밤 미리 준비(프라이밍) — (습관)
- 나쁜 행동에 일부러 단계 하나 더 추가해 마찰 늘리기 — (습관)
- 끊고 싶은 습관 → 어길 시 공개적·고통스러운 대가가 따르는 계약서 작성 — (습관)
- 작은 질문 하나를 포스트잇에 적어 눈에 잘 보이는 곳에 붙이기 — (반복)
- 줄이고 싶은 행동은 "한 번에 끊기" 대신 "한 모금/한 입 덜 하기"로 시작 — (반복)
- 상상 연습은 부담 없을 때만 시간을 늘리고 힘들면 다시 줄이기 — [감정] (반복)
- 같은 실수가 두 번 반복되면 시스템을 바꾸기 — [피드백] (실천)
- 원칙("~한 상황에서는 ~하라")은 감정이 차분할 때 미리 만들어두기 — [사고방식] (실천)

## 🪪 정체성

- "OO을 해야 한다" → "나는 OO한 사람이다"로 정체성 문장 만들기 — [습관] (습관·실천)
- "살 빼야지" → "나는 건강한 사람이다"처럼 프레임 전환 (모든 행동은 되고 싶은 사람에 대한 투표 한 표) — (습관)
- 한계를 과거형으로 바꾸기: "나는 ~를 못한다" → "나는 예전에 ~를 못했다" — [사고방식] (내면·실천)
- As If: 이미 그 상태인 것처럼 행동하기 (반복하면 실제 신경 경로 형성) — [사고방식] (내면·실천)
