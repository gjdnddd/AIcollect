## 📌 의사결정 원칙

### 결정 전 체크
- **모른다는 것 인정**: 중요한 결정 전 "확신하는 것 / 불확실한 것" 두 칸 나눠 적기. 불확실한 것이 많을수록 베팅 크기를 줄이고 정보를 더 구하는 신호
- **한 문장 요약 먼저**: "이 투자는 금리 하락을 전제로 한 베팅이다" — 한 문장이 안 나오면 이해 부족 신호
- **층위 체크**: ① 큰 그림 (이 결정이 내 목표·방향에 맞는가?) ② 디테일 (구체적 실행 계획이 현실적인가?) — 두 가지 모두 통과해야 실행
- **세 가지 도구 체크**: 논리(데이터·사실) + 직관(왜 이런 느낌?) + 신뢰도 높은 의견 → 셋이 일치하면 강하게 행동, 엇갈리면 더 파고들기
- **기댓값 표**: 성공/실패 확률 × 결과 크기로 간단히 계산. 숫자 정확하지 않아도 구조 자체가 감정적 결정을 막음

### 결정 타이밍
- **감정 올라온 직후 결정 금지**: 피곤할 때 / 화날 때 / 흥분했을 때 내린 결정은 반드시 재검토. 최소 하루, 가능하면 이틀 뒤 결정
- **고영향 / 저영향 분류**: 모든 고민을 적고 분류 → 저영향은 5분 안에 결정, 고영향은 충분한 시간 투입

## 📌 사고방식 원칙

### 에고·블라인드 스팟 관리
- **에고 지도**: 반박받으면 특히 기분 나빠지는 영역 3가지 적기 → 그 영역에서는 한 박자 늦게 반응 연습
- **블라인드 스팟 해소**: 신뢰할 수 있는 2~3명에게 "내가 못 보고 있는 것이 뭐냐"고 직접 물어보기. 반박하지 않고 끝까지 듣기
- **의견 충돌 시**: "만약 저 사람이 맞다면, 나는 무엇을 놓친 것인가?" 먼저 생각하기

### 일일 자기 점검 (3초)
- 오늘 상대 말을 끊었는가?
- 오늘 틀렸을 때 인정했는가?
- 오늘 다른 의견에 호기심을 느꼈는가?

### 분기 점검
- 3개월 전 대비 지금 달라진 것은?
- 지금 흐름이 계속되면 3개월 후는?
- 방향을 바꿔야 한다면 지금 무엇을 바꿔야 하는가?

## 📌 원칙 리스트 (달리오 방식)

> "~한 상황에서는 ~하라" 형식으로 작성. 감정이 차분할 때 미리 만들어두기.

- 투자 판단이 감정에서 나왔다고 느껴지면 하루 기다려라
- 반박이 불편하게 느껴지면 그 의견을 더 진지하게 들어라
- 같은 실수가 두 번 반복되면 시스템을 바꿔라
- 손실이 10% 넘으면 추가 매수 전에 하루 기다려라
- 직관이 강하게 올라오면 "왜 이런 느낌인가?"를 일지에 기록하라

## 📌 상태 관리 원칙 (내면의 탁월함)

### 즉시 사용 가능한 도구
- **박스 호흡 4-4-4-4**: 흥분·압박 시 즉시 사용. 들숨 4초 → 참기 4초 → 날숨 4초 → 참기 4초
- **STOP 기법**: Stop → Take a breath → Observe(지금 내 상태 관찰) → Proceed. 반응 전 한 박자 멈춤
- **앵커링**: 최상의 상태 기억을 특정 신체 신호(주먹·손가락)와 연결해두기. 필요 시 신호로 상태 재현
- **만트라**: 흔들릴 때 반복할 짧은 문구 하나 만들어두기. 예: "지금 이것만", "여기 지금"

### 하루 루틴에 넣을 것
- **아침**: 의도 설정 — "오늘 내가 원하는 상태는?"
- **매매 전**: 박스 호흡 + 앵커링
- **매매 중 결과 걱정 올라올 때**: 만트라 + 감각으로 전환
- **손실 후**: S-L-O-W + 서두름 제거 (바로 재진입 금지)
- **저녁**: 감사 연습 3가지 적기

## 📌 습관 설계 원칙 (Atomic Habits + Kaizen)

### 시작
- **정체성 프레임**: "OO을 해야 한다" → "나는 OO한 사람이다"로 전환. 모든 행동은 되고 싶은 사람에 대한 투표 한 표
- **2분 룰**: 새 습관은 "이 정도는 절대 실패할 수 없다"고 느껴질 만큼 작게 시작 (30분 운동 → 1분 제자리걸음)
- **작은 질문**: 막막할 때 "지금 당장 할 수 있는 가장 작은 행동은?" 매일 반복해서 자문

### 환경 설계
- **신호 배치**: 원하는 행동 신호(운동화, 책)는 눈에 보이는 곳에 / 나쁜 습관 신호는 시야 밖으로
- **습관 쌓기**: "[기존 확실한 습관]을 한 후, [새 습관]을 한다" 형식으로 연결
- **마찰 조절**: 좋은 습관은 마찰을 줄이고, 나쁜 습관은 단계를 하나 더 추가해 마찰 늘리기

### 지속
- **두 번 연속 거르지 않기**: 하루 빠졌으면 다음 날은 꼭. 빠진 날 자책 대신 복귀에 집중
- **작은 보상**: 큰 보상("끝나면 여행")보다 "할 때마다 받는 작은 보상"(5분 휴식, 좋아하는 음악)이 지속력 높음. 단 목표와 충돌 금지
- **주간 점검**: 매주 한 번 "이번 주 저지른 작은 실수는 무엇인가?" — 위기가 커지기 전에 균열 발견

## 📌 믿음·심리 원칙

- **한계를 과거형으로**: "나는 ~~를 못한다" → "나는 예전에 ~~를 못했다"
- **As If 원리**: 이미 그 상태인 것처럼 행동하기. 반복하면 실제 신경 경로가 형성됨
- **성공 재정의**: 결과·타인 비교가 아닌 "내 최선을 다했는가?"를 기준으로
- **숙달 추구**: 이기는 것이 목표가 아니라 성장과 숙달이 목표 — 압박이 기회로 바뀜
- **시각화**: 완벽한 결과가 아닌 어떤 역경에도 평정심 유지하는 자신을 시각화
