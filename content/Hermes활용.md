# Hermes 활용 가이드

> Hermes 에이전트 전용 슬래시(/) 명령어.
> 멀티 에이전트 자동화 툴 Hermes를 일상 업무·연구·개인 지식 관리(PKM)에 활용하기 위한 핵심 명령어.

---

## ① 상태 · 모델 제어

- **`/status`** — 현재 세션 ID, 대화 타이틀, 토큰 사용량 등 상태 요약 확인
- **`/reasoning [low / medium / high / xhigh]`** — AI의 사고 깊이(추론 단계) 조정. 복잡하고 정교한 로직엔 `high`·`xhigh`
- **`/model [모델명]`** — 실시간으로 최적의 LLM 엔진 교체
- **`/raw`** — 매 작업마다 요구되는 수동 승인(Approval) 절차를 생략, 중단 없이 실행하는 로우 모드
- **`/footer`** — 화면 하단에 실시간 토큰 소모량·모델 정보 인디케이터 토글
- **`/help`** — 지원하는 전체 명령어 가이드 호출

---

## ② 세션 · 컨텍스트 관리

- **`/compress`** — 컨텍스트가 한계에 다다랐을 때 기존 메시지 흐름을 스마트하게 압축·요약
- **`/resume`** — 과거 대화 세션 히스토리를 시각화 호출. 특정 세션명으로 과거 흐름에 복귀
- **`/rollback [숫자]`** — 원치 않는 방향으로 흘러갔을 때 특정 체크포인트로 즉시 되돌리기
- **`/branch`** — 기존 타임라인을 보존한 채 `Case A`·`Case B` 실험 분기를 만들어 병렬 테스트

---

## ③ 리서치 · 지식 관리 (PKM)

- **`/archive`** — 최신 학술 논문·디지털 아카이브 자원을 실시간 리서치·요약
- **`/llm_wiki`** — 인터넷 링크·리서치 결과물을 개인 위키 볼트(옵시디안 등)에 PDF 임베드 및 구조화 마크다운 노트로 자동 저장
  - 확장 팁: 스키마(Schema) 규칙에 속성을 미리 부여하면 사용자 개입 없이 AI가 지식을 연결·팽창시킨다
- **`/obsidian [검색어]`** — 로컬 PC의 옵시디안 볼트 경로를 추적해 내부 문서를 검색하고 답변 컨텍스트로 활용
- **`/workspace`** — 구글 API(크레덴셜) 연동으로 캘린더 일정 조회·이메일 추적 등 업무 비서 역할

---

## ④ 자동화 · 백그라운드

- **`/steer`** — AI가 답변을 출력하는 도중 즉시 개입해 실행 방향을 원하는 목적지로 전환
- **`/background`** — 장시간 소요되는 무거운 작업을 백그라운드로 돌리고 다른 작업 병행
- **`/goal [목표명]`** — 장기 목표·토큰 버짓(예: 20턴)을 설정하면 목표 달성까지 에이전트가 자율적으로 루프
- **`/update`** — 에이전트 엔진 자체를 최신 안정화 버전으로 자동 깃 풀링·업데이트
- **`/debug`** — 오류 발생 시 시스템 로그·인포메이션 리포트를 생성해 트러블슈팅 지원
