# 도구 선택 가이드

> 프로젝트 단계별로 어떤 AI 도구를 쓸지, 어떤 모델을 쓸지, 어떤 규칙을 참고할지 정리한 참조표.
>
> **사용 방법:**
> - **사용자 참고용**: 어느 단계에서 어떤 도구를 써야 할지 직접 판단할 때
> - **AI 지침용**: 세션 시작 시 그대로 던져주면 AI가 단계·도구·모델을 보고하고 진행

## 도구별 역할 요약

| 도구 | 역할 | 강점 |
|---|---|---|
| **Claude Chat** (Opus) | 구상·설계·의사결정 | 깊은 사고, 대화형 인터뷰 |
| **Claude Chat** (Sonnet) | 구상·셋업·간단 질문 | 빠름, 비용 효율 |
| **Claude Code** (Sonnet) | 구현·배포·파일 수정 | 파일 직접 편집, 코드 실행 |
| **Codex** (GPT) | 반복 코딩, 대량 작업 | 빠른 반복, GPT 모델 선택 |
| **Hermes** | 슬래시커맨드 자동화 | 반복 정리 작업 자동화 |
